# Accessibility lens (WCAG 2.2 AA)

Check the source first, then confirm runtime behaviour when a browser or an automated test is available (`~/.agents/klugzeug/browser-verification.md`). Mark anything that needs a person with a screen reader `[VERIFY]`.

## Semantics and names

- Interactive elements are real controls (`button`, `a href`, `input`), not `div` with `onClick`. Custom widgets follow the ARIA pattern for their role.
- Every control has an accessible name: visible text, `aria-label` when the text is an icon, or a programmatic label for form fields (WCAG 1.3.1, 4.1.2).
- Images have meaningful `alt`, or `alt=""` when decorative. Icon-only buttons have names.
- `id` attributes are unique in the rendered page. Items rendered in a list must not share a static `id`, because labels and `aria-describedby` then point at the wrong element.
- Headings are in order and describe their sections. Landmarks (`main`, `nav`) exist once per page.

## Keyboard and focus

- Every interactive element is reachable by Tab, operable with Enter or Space, and not trapped (WCAG 2.1.1, 2.1.2).
- Focus is visible in every state (WCAG 2.4.7, 2.4.11 for focus appearance).
- Dialogs and popovers move focus in on open, keep it inside while open, close on Escape, and return focus to the trigger (WCAG 2.4.3).
- Removed or re-rendered content does not drop focus to the document body.

## Forms and errors

- Each field has a visible label. Placeholder text is not the only label.
- Errors are tied to their field (`aria-describedby` or equivalent), and the first error receives focus on submit.
- Required fields are marked in text and programmatically (WCAG 3.3.1, 3.3.2).

## Dynamic content

- State changes that swap content are announced through a live region, or the focus moves to the new content (WCAG 4.1.3).
- Loading indicators are announced or given accessible text.

## Visual

- Text contrast at least 4.5:1, large text 3:1, UI components and focus indicators 3:1 (WCAG 1.4.3, 1.4.11). Check token values, not rendered screenshots alone.
- Content works at 200% zoom and at 320px width without horizontal scrolling (WCAG 1.4.4, 1.4.10).
- Respect `prefers-reduced-motion` for non-essential animation (WCAG 2.3.3).
- Colour is not the only way to convey state (WCAG 1.4.1).
